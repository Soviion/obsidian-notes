# Postman
— это самый популярный инструмент для работы с API (в первую очередь REST). Это приложение (desktop + web) + облачная платформа, которое позволяет отправлять запросы к API, смотреть ответы, тестировать, документировать и автоматизировать.

**Для чего используют Postman (основные цели):**
- Тестирование и отладка API (самое частое использование)
- Исследование неизвестного API (узнать, какие есть endpoints, параметры, ответы)
- Документирование API (создавать коллекции с примерами запросов/ответов)
- Автоматизация тестов (написать простые скрипты на JS для проверки ответов)
- Mock-серверы (имитировать API, когда бэкенд ещё не готов)
- Мониторинг (проверять, работает ли API в проде)

# Swagger (OpenAPI)
— это набор инструментов + спецификация OpenAPI

OpenAPI — это стандарт (машиночитаемый формат YAML/JSON), который описывает контракт API полностью: endpoints, методы, параметры, схемы данных, примеры, коды ошибок и т.д.

**Swagger** — это инструменты, которые работают с этим стандартом:
	**Swagger Editor** — онлайн-редактор для написания OpenAPI-файла
	**Swagger UI** — красивая интерактивная документация (самое известное — страничка с кнопками Try it out)
	**Swagger Codegen** — генерация кода клиента/сервера из спецификации

**Для чего используют Swagger/OpenAPI:**
- **Документация API** — основная цель (самая читаемая и актуальная документация)
- **Дизайн API** (design-first подход: сначала пишем спецификацию → потом код)
- **Валидация контракта** (проверяем, что реализация соответствует описанию)
- **Генерация клиентов** (автоматически создаём SDK на разных языках)
- **Тестирование** (базовое — через Try it out в Swagger UI)
