# **Реляционная База Данных**

**Реляционная база данных** — это тип базы данных, в которой информация хранится в виде **таблиц**, а связи между ними строятся на основе **ключей**.

Основные принципы реляционных БД:
1. **Табличное представление** – все данные организованы в таблицы
2. **Целостность данных** – система гарантирует, что данные корректны и согласованы
3. **SQL как язык запросов** – для работы с реляционными БД используется SQL (Structured Query Language)
4. **ACID-транзакции** – гарантируют надёжность операций даже при сбое
