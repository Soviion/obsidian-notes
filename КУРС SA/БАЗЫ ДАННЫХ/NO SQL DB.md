| Имя и описание                                                                                                                                         | примеры                                         | когда используется                                                                                                                                                            |
| ------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Документные БД** <br>Данные хранятся в виде документов (например, JSON). Каждый документ может иметь свою структуру.                                 | - MongoDB<br>- Couchbase<br>- Amazon DocumentDB | - Нужно хранить разнородные данные (например, разные типы пользователей)<br>- Данные меняются со временем, и структура не фиксирована<br>- Часто используется в CMS, CRM, IoT |
| **Ключ-значение (Key-Value Stores)**<br><br> Простые хранилища, где данные представлены в виде пар: ключ ↔ значение.                                   | - Redis<br>- Memcached<br>- Amazon DynamoDB     | - Для кэширования<br>- Хранение сессий, конфигов, временных данных<br>- Когда нужен очень быстрый доступ к данным                                                             |
| **Хранилища столбцов (Column-Oriented Databases)**<br><br> Данные организованы по столбцам, а не по строкам. Подходит для аналитики и больших объёмов. | - Cassandra<br>- HBase<br>- Apache Accumulo     | - Работа с большими объёмами данных (Big Data)<br>- Аналитические системы<br>- Логирование и метрики                                                                          |
| **Графовые БД**<br><br> Данные представлены в виде **узлов** и **связей между ними** .                                                                 | - Neo4j<br>- ArangoDB<br>- Amazon Neptune       | - Анализ социальных сетей<br>- Поиск связей между объектами<br>- Рекомендательные системы<br>- Модели знаний (knowledge graphs)                                               |
| **Поисковые БД**<br><br> Оптимизированы для **быстрого поиска и индексирования**.                                                                      | - ElasticSearch<br>- Solr                       | - Поиск по тексту<br>- Логирование и мониторинг<br>- Реализация функции "поиск" в приложениях                                                                                 |
