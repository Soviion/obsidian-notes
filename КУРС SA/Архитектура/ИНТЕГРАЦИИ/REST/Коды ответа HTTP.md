#### 1xx — Информационные (редко встречаются в реальной жизни)
- **100 Continue** — сервер получил заголовки запроса, клиент может отправлять тело.
- **101 Switching Protocols** — смена протокола (например, при переходе на WebSocket).
- **102 Processing** — сервер начал обработку, но ещё не готов ответить.
#### 2xx — Успех
- **200 OK** — всё хорошо, стандартный ответ на GET, PUT, PATCH.
- **201 Created** — ресурс успешно создан (обычно после POST).
- **202 Accepted** — запрос принят в обработку, но ещё не выполнен (асинхронные операции).
- **204 No Content** — успех, но тело ответа пустое (часто после DELETE или PUT без возврата данных).
#### 3xx — Перенаправление
- **301 Moved Permanently** — ресурс навсегда перемещён на новый URL (важно для SEO).
- **302 Found** (или 307 Temporary Redirect) — временное перенаправление (по умолчанию в многих фреймворках).
- **303 See Other** — перенаправление на другой URL, обычно после POST (чтобы избежать повторной отправки формы).
- **304 Not Modified** — ресурс не изменился (используется с кэшированием, ETag или Last-Modified).
- **308 Permanent Redirect** — как 301, но сохраняет метод запроса.
#### 4xx — Ошибки клиента
- **400 Bad Request** — запрос неверный, плохой синтаксис или параметры.
- **401 Unauthorized** — нужна аутентификация (нет или неверный токен/логин).
- **403 Forbidden** — клиент аутентифицирован, но доступ запрещён (нет прав).
- **404 Not Found** — ресурс не найден.
- **405 Method Not Allowed** — метод не поддерживается для этого URL (например, POST на страницу только с GET).
- **409 Conflict** — конфликт состояния (например, пытаемся создать уже существующий ресурс).
- **410 Gone** — ресурс был, но удалён навсегда.
- **413 Payload Too Large** — тело запроса слишком большое.
- **415 Unsupported Media Type** — неверный Content-Type (например, отправили JSON, а сервер ждёт form-data).
- **429 Too Many Requests** — слишком много запросов (rate limiting).
#### 5xx — Ошибки сервера
- **500 Internal Server Error** — общая ошибка сервера (что-то сломалось внутри, не вина клиента).
- **501 Not Implemented** — сервер не поддерживает запрошенную функциональность.
- **502 Bad Gateway** — ошибка шлюза (например, nginx не может связаться с backend).
- **503 Service Unavailable** — сервер временно недоступен (перегрузка, maintenance).
- **504 Gateway Timeout** — шлюз не получил ответ от upstream-сервера вовремя.
