
ACID — это набор свойств транзакций, обеспечивающих надежность работы с данными:
- **Atomicity (Атомарность):** Все операции в транзакции выполняются полностью или не выполняются вовсе.
- **Consistency (Согласованность):** После транзакции данные остаются в корректном состоянии.
- **Isolation (Изоляция):** Параллельные транзакции не влияют друг на друга.
- **Durability (Надёжность):** После фиксации изменения сохраняются даже при сбое системы.

Модель данных - формальное описание структуры хранения данных

Нормальные формы (Normal Forms) — это набор правил, которые помогают проектировать реляционные базы данных так, чтобы минимизировать избыточность данных и устранить нежелательные аномалии при добавлении, изменении и удалении записей.

| н.ф.                                | требование                                                                                         | что устраняет                                |
| ----------------------------------- | -------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| Первая нормальная форма (1NF)       | все атрибуты атомарны(неделимы) + нет повторяющихся групп                                          | списки в ячейке, многозначные поля           |
| Вторая нормальная форма (2NF)       | 1NF+ все атрибуты таблицы зависят от единственного первичного ключа                                | избыточность при составном первичном ключе   |
| Третья нормальная форма (3NF)       | 2NF+ нет транзитивных зависимостей: неключевой атрибут не зависит от другого неключевого атрибута. | избыточность и аномалии из-за транзитивности |
| Нормальная форма Бойса-Кодда (BCNF) | 3NF + каждый детерминант — кандидат на первичный ключ                                              | Более строгий случай 3NF                     |
| Четвёртая нормальная форма (4NF)    | Устраняет многозначные зависимости.                                                                |                                              |
| Пятая нормальная форма (5NF)        | Устраняет соединительные зависимости.                                                              |                                              |
