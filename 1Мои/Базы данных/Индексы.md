Индекс - вспомогательная структура данных, которая ускоряет поиск данных.
CREATE INDEX (name_of_index)
ON (table_name) ((поле таблицы));

- Индексам необходимо место для хранения
- При добавлении данных в БД сначала обновляется исходная таблица, а затем все ее индексы.


Типы индексов:
- Кластеризованный индекс: Автоматически создается для первичного ключа
- Декластеризованный индекс
