# Простые запросы

```
-- Вывести уникальные значения из столбца city

SELECT DISTINCT city FROM customers;
```

```
-- Вывести столбцы order_id, customer_id, amount из таблицы orders

SELECT order_id, customer_id, amount 
FROM orders;
```

```
-- вывести order_id, amount из orders сортировка по amount по убыванию

SELECT order_id, amount 
FROM orders 
ORDER BY amount DESC;
```
ASC — по возрастанию (по умолчанию), 
DESC — по убыванию).

```
-- Топ-5 заказов начиная с 11-го (страница 3, если по 5 на странице).

SELECT order_id, amount
FROM orders
ORDER BY amount DESC
LIMIT 5 OFFSET 10;
```
LIMIT — ограничить количество строк, 
OFFSET — пропустить первые N строк (для пагинации).

```
-- AS - переименовывает колонку для удобсвта чтения

SELECT 
    customer_id AS клиент, 
    amount AS сумма_заказа
FROM orders
WHERE status = 'completed';
```

```
-- Завершённые заказы дороже 1000 ИЛИ все заказы клиента 101 в 2025 году.

SELECT * FROM orders 
WHERE (status = 'completed' AND amount > 1000) 
OR (customer_id = 101 AND order_date >= '2025-01-01');
```

```
-- IN, BETWEEN, LIKE, IS NULL

SELECT * FROM orders 
WHERE customer_id IN (101, 102, 105); -- из значений списка 101, 102,105

SELECT * FROM orders 
WHERE amount BETWEEN 1000 AND 2000;  -- в диапазоне от 1000 до 2000 включительно

SELECT * FROM orders 
WHERE status LIKE 'comp%';  -- начинается на comp

SELECT * FROM orders 
WHERE status IS NULL; -- где статус NULL
```
- IN — значение в списке
- BETWEEN — в диапазоне (включительно)
- LIKE — поиск по шаблону (% — любые символы, _ — один символ)
- IS NULL — проверка на NULL (не = NULL!)

```
-- конструкция if/else внутри с case создаст столбец где будет категория заказа большой, средний, маленький по фильтру WHEN 

SELECT order_id, amount, 
	CASE 
		WHEN amount >= 2000 THEN 'Большой' 
		WHEN amount >= 1000 THEN 'Средний' 
		ELSE 'Маленький' 
	END AS размер_заказа 
FROM orders;
```

# Агрегатные функции — вычисления по группам строк.

```
-- по всей таблице выведет характеристическую таблицу по выполненым заказам

SELECT 
	COUNT(*) AS всего_заказов, 
	COUNT(order_id) AS заказов_с_id, -- то же самое 
	SUM(amount) AS общая_выручка, 
	AVG(amount) AS средний_чек, 
	MIN(amount) AS минимальный_заказ, 
	MAX(amount) AS максимальный_заказ 
FROM orders 
WHERE status = 'completed';
```

```
-- выведет id клиентов с их количество заказов и общей вырочкой по завершенным заказам, и только те клиенты, у которых 2+ заказов 

SELECT customer_id, 
	COUNT(*) AS кол_во_заказов, 
	SUM(amount) AS выручка 
FROM orders 
WHERE status = 'completed' 
GROUP BY customer_id 
HAVING COUNT(*) >= 2 -- только клиенты с 2+ заказами 
ORDER BY выручка DESC;
```
- GROUP BY — группирует строки для агрегатных функций
- HAVING — фильтр по результатам агрегатов (аналог WHERE, но после GROUP BY)

# Типы JOIN'ов

| INNER JOIN    | Возвращает только те строки, где есть совпадение в обеих таблицах. Самый строгий и часто используемый.                                                          |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **LEFT JOIN** | Возвращает все строки из левой таблицы (orders) + совпадающие из правой. Если совпадений нет — поля из правой таблицы будут NULL. Самый популярный в аналитике! |
| RIGHT JOIN    | Возвращает все строки из правой таблицы (customers) + совпадающие из левой. Если нет совпадения — поля из левой будут NULL.                                     |
| FULL JOIN     | Возвращает все строки из обеих таблиц. Где нет совпадения — NULL в соответствующих полях.                                                                       |

#### INNER JOIN (просто JOIN)
**Пояснение**: Возвращает только те строки, где есть совпадение в обеих таблицах. Самый строгий и часто используемый.
```
SELECT 
    o.order_id,
    o.amount,
    c.name,
    c.city
FROM orders o
INNER JOIN customers c ON o.customer_id = c.id;
```

#### LEFT JOIN (LEFT OUTER JOIN)
**Пояснение**: Возвращает **все строки из левой таблицы** (orders) + совпадающие из правой. Если совпадений нет — поля из правой таблицы будут NULL. Самый популярный в аналитике!
```
SELECT 
    o.order_id,
    o.amount,
    c.name,
    c.city
FROM orders o
LEFT JOIN customers c ON o.customer_id = c.id;
```
- Все 4 заказа из orders.
- Для order_id=4 (customer_id=103) — name и city будут NULL (клиента 103 нет в customers).
- Полезно: найти заказы от "неизвестных" клиентов или всех клиентов с заказами/без.
