# Идемпотентность

Идемпотентность в контексте HTTP означает, что повторное выполнение одного и того же запроса приводит к одинаковому результату, как если бы он был выполнен один раз. Это важно для надежности и предсказуемости работы веб-приложений.

**POST - не идемпотентный** - при повторной отправке может создать новые данные, запись 
**PATCH - (не)идемпотентный** - при повторной отправке, результат может оличаться
