**dempotency Key** (или Idempotency Token) — это уникальный идентификатор, который клиент добавляет к запросу (обычно в заголовке), чтобы сервер мог определить:  
**«Этот запрос уже выполнялся?»**  
Если да — вернуть **тот же ответ**, не повторяя операцию.

При повторных запросах (таймаут, сбой сети, ретрай) может произойти:
- Двойная оплата.
- Дублирование заказа.
- Лишние изменения данных.

Идемпотентный ключ ***генерируется на клиенте***, и проверяется на сервере.

По умолчанию не реализован, используется только там, где нельзя допускать ошибки, в банковской сфере, транзакции ид.


### Структура запроса с ключом 

```
POST /payments 
Headers: 
	Content-Type: application/json 
	Idempotency-Key: <123e4567-e89b-12d3-a456-426614174000> 
Body: { 
	"amount": 100, 
	"currency": "USD" 
}
```

### Алгоритм сервера:

```
if (Idempotency-Key существует): 
	вернуть сохранённый ответ 
else: 
	выполнить операцию 
	сохранить ответ + ключ 
	вернуть ответ
```
