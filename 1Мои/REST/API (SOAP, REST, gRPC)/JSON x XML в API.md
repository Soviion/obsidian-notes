**JSON (JavaScript Object Notation)** — это текстовый **формат** обмена данными, основанный на синтаксисе JavaScript, но независимый от него.
```
{
  "name": "Ivan",
  "age": 30,
  "skills": ["JavaScript", "HTML", "CSS"]
}
```

**XML (eXtensible Markup Language)** — это расширяемый **язык** разметки, созданный для описания данных с помощью тегов.
```
<name>Ivan</name>
  <age>30</age>
  <skills>
    <skill>JavaScript</skill>
    <skill>HTML</skill>
    <skill>CSS</skill>
  </skills>
```

| Критерий           | JSON                                         | XML                                                  |
| ------------------ | -------------------------------------------- | ---------------------------------------------------- |
| Синтаксис          | ключ - значение                              | встроенные теги ( открывающий тег - закрывающий тег) |
| компактность       | + легкий, меньше вес                         | - большой из-за вложенных тегов                      |
| читаемость         | + простая структура ключ-значение            | - сложная из-за вложенных тегов                      |
| скорость обработки | + быстрее                                    | - медленнее, из-за сложности структуры               |
| поддержка типов    | + есть встроенные числа, bool-значение, null | - все как строки                                     |
| гибкость           | - ограничен по структуре                     | + атрибуты, пространства имен                        |
| стандарты          | + для rest api и др                          | + используется в SOAP                                |
| расширяемость      | - Нет встроенной поддержки трансформации     | + namespace, XSLT и др                               |
### **Когда JSON лучше для API**

- REST API, веб и мобильные приложения.
- Когда важны **скорость**, **простота**, **минимальный размер данных**.
- Для обмена данными между сервисами, где нет строгих требований к схеме.

### **Когда XML лучше**

- SOAP API, корпоративные интеграции.
- Сложные документы, требующие строгой схемы и валидации.
- Когда нужны **трансформации** (XSLT) или **пространства имён**.
